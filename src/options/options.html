Some video ads (YouTube's in-stream ones) play through the same player as real content, so they can't be blocked outright. This dims them instead of removing them, automatically, no picking required. On by default. Best-effort — depends on YouTube's current markup — so turn it off here if it ever misfires. Still see one you want gone entirely? Use "Block an element…" from the toolbar popup.

Aggressively remove sponsored posts

Instagram, LinkedIn, and YouTube render sponsored posts with class names that change per session specifically to dodge fixed filter rules. This watches feeds as you scroll and removes any post labeled "Sponsored," "Ad," "Promoted," or "Paid partnership" as it renders, instead of relying on a fixed selector. Off by default: a label match, not a fixed rule, so it carries a little more false-positive risk than everything else here — for when you want feeds fully cleaned, not just what static rules catch.

            What this is

            Moat blocks ads, trackers, and hijacked popups and redirects, on Chrome and Firefox. It has no nag screens, no onboarding tabs, and no "rate us" prompts. The full README explains how the blocking, popup firewall, and cosmetic filtering work.

            Privacy

            Everything on this page is stored locally in your browser. That includes protection state, paused sites, filter list choices, and custom rules. None of it is sent anywhere.

            There is one exception. Once a day, Moat fetches a small public file from GitHub listing known popup and redirect domains, so the list stays current between store updates. That request carries no settings or browsing data. It is a plain GET, and it reveals your IP to GitHub the same way visiting any website would.

            If "Reduce fingerprinting" is on, Moat generates a random identifier locally to seed noise added to canvas and audio reads. That identifier never leaves your device.

            This installation is managed by your organization. Your administrator can see and set the policy values below. They cannot see your individual browsing.

            Debugging

            The rule-match logger shows which of Moat's compiled rules matched each request on a tab, for diagnosing a filter or heuristic that stops working. It's a development tool: Chrome only exposes the data it needs when the extension is loaded unpacked (developer mode), so this page will say so and show nothing on a normal install.
