            About Moat

            Moat blocks ads, trackers, and hijacked popups on Chrome and Firefox. The full README explains exactly how the blocking, popup firewall, and cosmetic filtering work.

            Keyboard shortcut: Ctrl+Shift+M (Cmd+Shift+M on Mac) toggles protection on/off globally. Rebind or view it at chrome://extensions/shortcuts (or the Firefox equivalent).

            Privacy

            Everything on this page is stored locally in your browser and never leaves your device.

            Filter Updates: Once a day, Moat pings GitHub to update its redirect domain list. This is a standard network request and carries no browsing data.

            Fingerprinting: If "Reduce fingerprinting" is enabled, Moat generates a random local identifier to block trackers. This identifier is never transmitted.

            Enterprise Notice: This installation is managed by your organization. Your administrator can see and set the policies below but cannot see your individual browsing history.

            Debugging

            The rule match logger is a development tool that shows which compiled rules matched specific network requests. It is only visible when the extension is loaded unpacked in developer mode.

            Backup & restore

            Save your settings to a file, or load a previously saved one. Your device's fingerprint-resistance identifier is never included.

            Sync settings across devices

            Mirrors your settings through your browser's own sync account. Off by default. Seeds a new install once; doesn't live-merge changes made on two devices at once.
