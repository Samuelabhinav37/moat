Moat Support

Fix a site that looks wrong, report a problem, or find an answer.

A site looks broken

Pause Moat on that one site. Everywhere else stays protected.

  1. Click the Moat icon in the toolbar.
  2. Turn off the switch for this site.
  3. The page reloads without Moat.
See it in action

Report a problem

Tell us about ads that got through or a page Moat broke. Fixes reach everyone in the daily filter update.

  1. On that site, click the Moat icon.
  2. Choose Report a problem and pick what went wrong.
  3. Press Send. You see every field before it goes.

Send feedback

After you've used Moat for a while, it asks once how it's going. You can always tell us more on GitHub.

  1. Answer the one question in the Moat menu, or skip it.
  2. Add a note if you like. It's optional.
